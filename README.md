# WillowFolia

WillowFolia — a plant collection dossier and growth diary (MVP).

This repository contains an Expo (React Native + TypeScript) scaffold, Supabase migrations, and a mocked data flow to get started quickly.

Quick start (local, using mocks)

1. Install dependencies
   npm install

2. Run the app (Expo)
   npx expo start

3. Use the app with mock data by default. To enable Supabase later, set environment variables as documented in .env.example and follow the README migration steps.

Important: this repo contains placeholders and no real secrets. Add SUPABASE / REVENUECAT / SENTRY secrets in GitHub Settings → Secrets when ready.

See README for full setup instructions.
